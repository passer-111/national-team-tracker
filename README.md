# A股国家队持仓跟踪

跟踪 **中央汇金系**（中央汇金投资 / 中央汇金资产管理）在 A 股的持仓变动，静态网页看板 + Python 抓数脚本，数据落盘为 JSON，可直接用 GitHub Pages 发布。

- 个股维度：定期报告披露的十大流通股东中的汇金系持仓（季报口径，准确但有滞后）
- ETF 维度：重点宽基 ETF 的成交额与份额变化（日频，作为托底力度的高频代理指标）

## 页面功能

| 视图 | 内容 |
| --- | --- |
| 持仓总览 | 最新报告期持仓只数、持股市值、环比变化、新进/退出/增持/减持，以及各期市值与只数走势 |
| 个股明细 | 全部持仓个股的持股数、占比、环比变动、期末市值与最新市值，可按列排序、按代码/名称搜索，点击展开历史各期持仓 |
| ETF 托底力度 | 重点宽基 ETF 合计成交额及其 20 日均值的对比、放量倍数、5/20 日份额变化 |
| 口径与说明 | 国家队口径、候选池、数据来源与免责说明 |

## 目录结构

```
.
├── index.html            静态看板入口（GitHub Pages 直接发布根目录）
├── assets/               样式与前端逻辑（原生 JS + SVG 图表，无外部依赖）
├── data/                 脚本产出的数据（holdings.json / etf.json / meta.json）
├── scripts/
│   ├── config.py         国家队口径、候选池、ETF 观察池等配置
│   ├── http_utils.py     带重试的 HTTP 会话与并发工具
│   ├── fetch_holders.py  十大流通股东抓取与汇总
│   ├── fetch_etf.py      ETF 行情与份额抓取
│   └── run_all.py        一键更新全部数据
└── cache/                抓取原始响应缓存（不入库）
```

## 使用

```bash
pip install -r requirements.txt

python scripts/run_all.py              # 全量更新（持仓 + ETF）
python scripts/run_all.py --skip-etf   # 只更新持仓
python scripts/run_all.py --refresh    # 忽略本地缓存重新抓取
python -m http.server 8000             # 本地预览：http://localhost:8000
```

抓取采用两阶段策略以控制请求量：先用最近两个报告期扫描全候选池筛出命中股票，再仅对命中股票回溯历史报告期；所有原始响应缓存在 `cache/`，增量更新只会抓取新增报告期。

## 数据口径

- **国家队识别**：十大流通股东名称命中「中央汇金」「汇金资管」，并区分
  「中央汇金投资」（控股股东型长期持股）与「中央汇金资管」（市场化持仓）两类。
- **持股市值**：持股数 × 报告期末（或之前最近交易日）收盘价，为估算值，非实际市值。
- **变动**：依据定期报告披露的「变动」字段，未披露变动计入「不变」；「新进」按首次出现统计。
- **ETF 份额**：上海证券交易所每日申赎清单口径，仅覆盖沪市 ETF；深市 ETF 仅有成交额。
- **ETF 汇金标记**：`scripts/config.py` 中 `ETF_WATCH` 的 `state_owned` 字段为人工维护的
  公开报道口径，可按需要增改。

数据来源：东方财富（十大流通股东、日线行情）、上海证券交易所（ETF 份额）。全部为免费公开接口。

## 部署到 GitHub Pages

```bash
git remote add origin <你的仓库地址>
git push -u origin main
```

随后在仓库 Settings → Pages 中选择 `main` 分支的根目录即可发布；每次本地跑完脚本后提交 `data/` 目录并推送，页面数据随之更新。
